# V6.8.1 报告可读性优化

9月8日原港股邮件打印件共8页。诊断信息占据首页，唯一趋势通过项目位于第4页，同一股票的说明被拆页；缺失趋势日期显示为 nan。

## 新阅读顺序

1. 本次结论：严格入场、合理估值、趋势子集三个统计，附优先研究线索及距离严格触发上限最近的项目。
2. 严格入场条件：现价、触发上限、价格距离、估值折价及财报口径。较远等待名单用简表。
3. 合理估值观察：趋势通过项目靠前，现价与研究上限并列，明确等待价格、等待趋势、数据不足和状态复核。
4. 数据与风险附录：主要拦截原因、现金流证据覆盖及一次性阅读口径说明。各项原因可重叠，不能相加。

研究估值上限与严格触发上限始终明确区分。旧评级样本、完整原因和全部扫描记录仍可在 CSV 中核查，不以减少报告篇幅为由改变筛选状态。

## 显示与兼容

- 手机窄屏将观察池表格显示为卡片；桌面和打印显示三列表格。
- 打印重复表头，避免股票行和重点卡片跨页拆开；章节按用途分页。实际页数随候选数量及邮件客户端的打印样式支持变化。
- 港股显示香港时间，美股显示纽约时间并按日期处理夏令时。趋势日期保留对应交易日，不做时区偏移。
- 缺失日期显示“未提供”，没有趋势评估的价格等待项目不展示无意义日期。
- 保留扫描开始、完成、耗时、覆盖数量及估值模型版本。版式版本与模型版本分别展示，本次不让估值缓存失效。
- 原报告中的历史回放风险说明继续保留；历史回放不展示实时观察池。
