# V6.7 严格入场观察规则

本次优化沿用用户所述《安全边际》的保守估值、避免永久损失、等待折价的方向。以下数值是本项目的初始工程规则，不是书中给出的公式，也不是经过回测拟合或证明有效的买点。系统提供研究候选，不执行交易。

## 两个百分比必须分开

`discount_to_value = (V - P) / V` 是相对保守估值的折价率。

`upside_to_value = (V - P) / P` 是回到估值的潜在上涨空间。

旧字段 `margin_of_safety` 继续保留第二种口径，兼容原来的 S/A/B 评分与历史压力测试。它不是新入场标准。例如价格 100、估值 150，旧 MoS 为 50%，折价率只有 33.33%。安全边际没有唯一量化定义，产品必须说明分母，不能将两个数字混用。[CFA：Margin of Safety: The Lost Art](https://rpc.cfainstitute.org/blogs/enterprising-investor/2015/margin-of-safety-the-lost-art)

## 价格与质量同时达标

全部默认值集中在 `src/opportunity.py` 的 `EntryPolicy`，调整时应同时递增 `entry_policy_version`。默认主规则如下。

| 条件 | 默认要求 |
|---|---|
| 保守价值折价 | 普通经营公司至少 35%；年报回退至少 40%；周期公司至少 50% |
| 压力价值折价 | 至少 10% |
| Owner FCF 收益率 | 至少 8%；超过 25% 需先排查异常 |
| 历史现金流 | 至少 3 年；至少 3 年为正，正值年份比例至少 80% |
| 利润与现金流 | 近期净利润、营业利润率、近期/多年现金流为正 |
| 现金转换率 | Owner FCF / 净利润至少 70% |
| 三年股本变化 | 增发稀释不超过 5%，不足完整三年不得猜测 |
| 净负债公司 | 净债务/EBITDA 不超过 3 倍；利息覆盖至少 4 倍 |
| 流动性 | 美股日均成交金额至少 100 万报价货币，港股至少 500 万港元；低于 1 元不进入 |
| 数据完整性 | SBC、现金、总债务、股本、报告期、报价币种均须有证据 |
| 时间 | 基本面抓取不超过 8 天；行情不超过 5 个自然日；TTM 最新报告期不超过 200 天，年报不超过 550 天 |
| 风险封顶 | 有陷阱标记、严重质量封顶、股本/市值错配均不能进入 |

5 个自然日的行情容忍用于周末等间隔，并不意味着停牌股可交易；超过该时间或日期缺失将停止发入场信号。报价仍是数据源最近成交/收盘数据，不能当作可立即成交的报价。

价格触发上限取三个约束的最低值：

```text
entry_price = min(
    保守每股价值 × (1 − 要求折价率),
    压力每股价值 × 90%,
    Owner FCF / 隐含股数 / 8%
)
deep_entry_price = min(entry_price, 保守每股价值 × 50%, 压力每股价值 × 75%)
distance_to_entry = entry_price / 当前价格 − 1
```

距触发上限为负数时，表示价格还需下降的比例；正数表示现价已经低于上限。深折价价是第二个观察价位，不自动对应加仓、仓位比例或止损。

## 压力情景与估值修复

压力估值将正的 FCF/净利润降低 30%，现金、NCAV、有形权益降低 20%，不使用正增长，折现率提高 2 个百分点；债务保持不变。重新运行相同估值方法并应用相同控股公司折价。这个压力情景不是清算价值，不是最坏情形或股价下限，真实损失可能更大。

PE 直接估算股权价值，不再额外加现金减债务。Owner FCF 引擎仍然是保守筛选近似：经营现金流减资本开支、SBC，再保留净债务储备折扣；它不是严格按 FCFF/WACC 或 FCFE 构建的企业估值模型。现金是否受限、少数股东权益、维护性资本开支、营运资金和再融资等仍需逐项复核。严格估值需要区分企业与股权现金流及其匹配的折现率。[CFA：Free Cash Flow Valuation](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)

已修复的计算问题：

- 非正估值保留为零，不再从估值候选里悄悄删掉。
- 已知亏损不再被“只取正值”的正常化逻辑忽略。
- 缺失现金/总债务不当成零；长期债务不能冒充总债务。
- CapEx 无论数据源使用正负号都按支出扣除；SBC 缺失不假定为零。
- TTM 不跨缺失季度补足四季；现金流与损益报告期不一致时一起回退到年报。
- 港股换汇保留股数、比率不变，财务摘要中的金额也使用汇率转换。
- 三年稀释使用四个年度股本，不能用四个季度替代。
- 现价使用未复权 Close，复权历史收益价不混入当前估值。
- 每次价格刷新重新应用质量封顶，重算现金流与资产负债评分；失败回退价不会触发入场。
- 模型版本变化使缓存失效；抓取失败不缓存成七天有效数据；连续五次限流停止全池请求，保留此前公开状态。
- 主观 `true_opportunity` / `too_strict` 标签保留为注释，不再自动加分或抬高估值；保守下调与陷阱否决仍保留。

## 状态、变化与留存

“价格达标·入场复核”与“深折价·入场复核”是研究触发；“接近触发价”表示价格在触发上限上方 10% 范围内；“等待价格”表示质量通过但仍不够便宜。“数据待补齐”与“风险未通过”不显示可操作触发价。金融、REIT 仍需专门模型。

首次升级或首次观察不声称发生价格穿越。后续区分价格进入区间、估值变化后达标、质量恢复、退出区间与状态未变。保守价值下修超过 15% 时暂停入场；下修参考值保留在 `value_review_anchor`，跨扫描保持，直到估值恢复至参考值的 85% 以上。人工完成复核但未恢复时，仍应通过代码/数据审查明确更新该参考状态，系统不自动解除。

每日完整扫描继续保存 `state/mos_market_latest.csv` / `state/hk_mos_market_latest.csv`。另追加 `state/mos_entry_history.csv` / `state/hk_mos_entry_history.csv`，记录达标、接近、下修及退出事件；排除私人持仓，不发送额外邮件。CSV 保存观察时间、行情时间、当时估值、阈值和状态。它用于今后的前向检验，不是完整 point-in-time 财报档案。每日 Actions 的结果 artifact 保留 90 天（受仓库允许上限影响）。

现有熊市/历史模块仍有当前财报配历史价格、当前股票池和股本等偏差；历史结果强制标为 `HISTORICAL_ONLY`，不会产生当前入场提示。未来评估应使用当时存下的信号，纳入退市、交易成本、分红拆股、未完成持有期及基准；不能把当前模型在历史低点的漂亮数字当作证据。
