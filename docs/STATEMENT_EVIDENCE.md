# V6.7.3 财报证据补录与诊断

最新港股 V6.7.2 扫描中，非金融且未跳过的 1,136 只股票有 531 只缺 Owner FCF、1,103 只使用年报回退。2026-09-06 从本机抽查 0151.HK、0552.HK、2555.HK，yfinance 年度现金流均返回空表；这只反映当次请求结果，不能据此断言这些公司没有披露现金流，也无法确认全池缺失原因相同。

本版提供逐项诊断和审核后财报补录的实际计算路径。`data/hk_statement_evidence.json` 已包含 0151.HK 两个历史年度（截至 2025-03-31 与 2024-03-31）的部分财报项目。数据来自 [2024/25 港交所正式年报](https://www.hkexnews.hk/listedco/listconews/sehk/2025/0717/2025071700258_c.pdf)，已提取文字并逐项目视核对印刷第 107、111 页（PDF 第 109、113 页）。SBC 未取得足够证据，省略该字段；这些补录不能生成可用 Owner FCF 或绕过入场门槛，也不代表最新年报已经补齐。

金额按人民币千元乘 1,000 转换。2024/25 经营净现金流为 4,161,620,000 元；资本开支合计物产设备、土地权利、无形资产现金支出为 640,573,000 元，未计融资段租赁付款。净利润采用合并年度利润而非归母利润；若供应商采用另一口径产生差异，系统将拒绝补录并要求复核。2023/24 使用同份年报比较列，不能把公告日期回填成当年已知日期。全池实际覆盖率改善仍待新扫描核验。

## 诊断结果

下一次完整扫描的结果 CSV 与 data-quality diagnostics CSV 新增：

| 字段 | 含义 |
|---|---|
| `annual_cashflow_status` | 原数据源年度现金流 AVAILABLE / UNAVAILABLE / NOT_FETCHED；补录后仍保留原状态 |
| `annual_cashflow_missing` | 补录后 OCF、资本开支、SBC 整项缺失，或最近五个非全空报告列中的具体缺失日期 |
| `financial_period_source` / `trailing_fetch_status` | 四季合计、数据源十二个月或年报，以及十二个月请求核验结果 |
| `statement_evidence_status` | NONE 无记录、SUPPLEMENTED 已填缺口、MATCHED 与已有值一致、REJECTED 拒绝整只股票补录 |
| `statement_evidence_audit` | JSON 形式的来源 URL、报告页码、公布/审核日期、审核者、补录字段与拒绝原因 |
| `entry_data_issues` / `entry_risk_issues` | 缺失证据与已识别风险分别保留，可能同时存在 |

这些 CSV 沿用现有 Actions artifact 上传路径，无需新增数据服务或账户。报告首页新增原数据源年度现金流未返回数和已采用补录数。未返回可能包含请求失败及供应商无数据，当前不把两者强行区分。

## 如何录入经核实的年度报表

一条记录代表一只股票的一个完整年度，最多补收入利润和现金流表；不补股价、股本或资产负债表，不直接写入估值、评级或触发价。金融股与地产仍沿用专门模型限制。证据必须来自公开港交所公告 PDF，并逐项核实证券主体、合并口径、单位、现金流定义、SBC 附注及重述情况。[港交所公告检索](https://www.hkexnews.hk/homelcicontentsearch.html)

以下仅为结构说明，空值和 `verified: false` 无法通过核验，不能直接作为生产记录：

```json
[
  {
    "ticker": "0151.HK",
    "currency": "CNY",
    "period_start": "YYYY-MM-DD",
    "period_end": "YYYY-MM-DD",
    "published_at": "YYYY-MM-DD",
    "reviewed_at": "YYYY-MM-DD",
    "source_url": "",
    "source_pages": "",
    "reviewed_by": "",
    "verified": false,
    "scope": "consolidated",
    "unit": 1,
    "values": {
      "revenue": null,
      "net_income": null,
      "operating_income": null,
      "operating_cash_flow": null,
      "capital_expenditure": null,
      "sbc": null
    }
  }
]
```

金额必须先按原财报单位换算成原币种“元”，不能把千元、百万元原数填入。可选字段为 `sbc`、`gross_profit`、`ebitda`、`interest_expense`，未知就省略。SBC 虽可在部分补录中省略，Owner FCF 及入场仍要求其证据；只有报告明确支持零值时才能填零，没有单列不能直接认定为零。资本开支须完整核实现金支出范围，不以净投资现金流冒充。

系统执行这些机械核验，但不会自动证明审核者身份、PDF 真伪或数字与页码一致；出处及转录正确性仍须人工核实：

- 仅接受 HTTPS 的 `www.hkexnews.hk` / `www1.hkexnews.hk` PDF 地址。
- 起止日间隔 330–380 天；截止日不晚于公告日，公告日不晚于审核日，审核日不在未来。不接受半年累计报表或同一股票重复/近邻年度。
- 币种与数据源财报币种一致，单位严格为 1，合并口径、页码及审核记录完整。
- 五个必需字段（收入、净利润、营业利润、经营现金流、资本开支）均为有限数字，所有已提供的可选字段也须为有限数字；零和亏损保留，未知字段、字符串数字、NaN/Inf 被拒绝。SBC 省略不会自动生成零。
- 只填缺失值；已有字段超过 `max(1 原币种单位, 原值约百万分之一)` 的差异视为冲突。CapEx/SBC 符号先按支出绝对值统一。冲突时该股票全部补录回滚，入场标注待复核，不能用补录悄悄改写已有数字。
- 补录在换汇前执行一次，之后仍须通过三年以上 Owner FCF、SBC 覆盖、报告期、股本、偿债等原有门槛。一年补录成功不等于满足入场证据。

## 生效和验证

补录文件内容哈希写入港股缓存。文件发生任何变化都会使港股缓存失效；仅刷新旧快照价格时也会要求重新完整扫描。首次升级模型或数据重新生成，不应将变化理解为市场价格穿越。

81 项离线测试通过。模拟整条链路确认：空年度现金流可以由经审核记录恢复、只换汇一次、一年数据仍受历史不足拦截。已录入的旺旺真实年报记录通过导入校验，但 SBC 仍缺失，不能宣称其严格入场证据已经补齐。公开年度现金流三股抽查为空，未验证新版本全池数据覆盖率。此版不调整估值参数、不降低质量或折价门槛，未重跑全市场、未发送邮件。
