# V6.10.0：2–10个交易日短线实验池

V6.10.0新增独立的[强势回踩再转强策略](PULLBACK_POLICY.md)，与下文放量突破共用行情、轮换覆盖和邮件流程，分别记录模拟结果。每个策略最多展示3个计划和4个预备；覆盖按股票计数，状态按策略项计数。下文参数表是原breakout-1规则，回踩参数见独立说明。

## V6.9.1机会发现与送达修复

下文V6.9.0固定100只和长报告邮件流程已由本节替代，突破成交规则仍为breakout-1，既有模拟记录保留。

- 在原基础门槛之后，先用最近公开扫描的成交额≥2000万当地货币做预筛；按行业交错、行业内成交额排序，再使用持久化游标轮换，每轮最多300只。最多100个优先位置用于复核原NEAR/PENDING，其余继续轮换；既有模拟持仓另外跟踪。新取的60日日线仍须再次通过原20日平均成交额条件。不是全市场扫描，也不是每天覆盖所有合格股票。
- 行情请求分批20只，约18分钟后不再启动新批次；当批请求仍可能继续等待。返回不足时报告DATA，保留模拟记录的待核验状态。本轮未选择、实际返回、数据失败分别计数，不能用“没有计划”代表全市场没有机会。
- 条件逐项记录：均线向上、相对基准为正、收盘突破、量比≥1.5；保存距前20日最高价的位置及尚缺条件。
- 均线及相对强度满足、距前20日高点绝对距离≤3%，但未通过全部条件时归入NEAR（初始工程门槛）。不生成触发价或模拟仓位。满足条件后的真实计划仍须重新核验原风险距离与扣费盈亏比。
- 最多展示5个计划（按20日相对强度、量比排序）和8个预备（按距突破位置排序），明确显示展示数/总数。不是胜率或收益概率排名。
- 原premarket_scan在进入全量财报循环前生成并发送短线简报；沿用既有SMTP收件人和每日一次频率，之后不再追加发送完整价值邮件。完整价值扫描及文件产物照常完成，简报HTML也上传。DRY_RUN不会发送，手动模式不变。本次开发只进行模拟发送测试，不向真实邮箱发测试邮件。
- 简报使用前一盘后快照，不额外等待新行情，也不保证实时触发。任务创建/依赖安装延迟依然存在；超过开盘会明确标注。尚未增加实时通知或账户级仓位控制。

原系统回答“企业是否便宜”，原趋势跳过最近21个交易日，不适合直接作为2–10天买点。本版增加独立的日线放量突破实验，不降低厚安全边际门槛，也不把合理估值上限当成短线目标。工程规则可运行不等于有盈利优势；不宣称牛市、更多信号或更高收益。

## 运行与展示

`python src/short_term_scan.py --market hk`（美股用 `us`）。只读取公开市场 CSV，不读取持仓、邮箱或券商账户。最近完整扫描须在8天内，普通股票、已知正净资产、公告补录无冲突；按已有成交额选最多100只，再核验日线成交额。不沿用价值折价、ROE或Owner FCF门槛。这不是完整的破产、造假或财报事件筛查；尚未接入可核验的事件日历，故只作模拟研究。

独立 GitHub Actions `MOS Radar - Short-term research` 在周一至五 UTC 09:23（港股）和21:37（美股）计划运行，也可手动选择市场。任务只写公开研究状态和上传HTML/CSV产物，不额外发邮件。原每日邮件读取最新短线状态。GitHub定时任务可能延迟；本模块不提供实时盯盘。首个计划生成前报告明确显示尚无可用快照。

`state/hk_mos_short_term.json`、`state/mos_short_term.json` 持久化计划和逐笔记录；其余 short CSV/HTML 作为工作流产物。既有模拟持有即使退出100只范围，也继续抓取行情跟踪。缺数与公司行动不会被当成零收益或删除；损坏状态文件使任务失败，禁止悄悄清空历史。两个市场分开维护，禁止将两种货币的逐笔收益当成组合收益。

## 初始规则（尚未做收益验证）

| 条件 | 规则 |
| --- | --- |
| 数据 | 最近60个完整交易日日线连续，股票与基准日期一致；至少保留收盘后20分钟缓冲 |
| 日历 | XHKG / XNYS，处理节假日、半日市、美国夏令时；非常规停市仍须核实 |
| 流动性 | 美股价≥US$5 / 港股价≥HK$2；前20日平均成交额≥2000万当地货币 |
| 趋势 | 收盘价>20日均线>50日均线；20日涨幅超过标普500/恒指 |
| 突破 | 收盘超过此前20日最高价；当日成交量≥此前20日均量1.5倍 |
| 触发/追价 | 信号日最高价×1.001；最高追价=触发价+0.25×ATR14 |
| 止损/目标 | 触发价−1.5×ATR14；触发价+3.75×ATR14（毛收益目标2.5R） |
| 风险距离 | 最高追价到止损之间的距离占最高追价1.5%–8%；估计扣费后盈亏比≥1.5 |
| 有效期 | 仅下一交易日常规时段；开盘后才生成的计划作废，不补记早盘成交 |
| 退出 | 碰止损或目标退出；最晚含买入日在内第10个交易日收盘退出，风险退出可以早于2天 |

指标使用归一到最新原始收盘价单位的复权OHLC；触发价使用原始价格。近21日拆合股暂停生成新计划，避免成交量单位混乱。已知公司行动发生在模拟持有/待触发期间时暂停收益判断，需要人工复核，尚未自动处理现金红利与拆合股。

## 前瞻模拟与成本

首次出现的计划在记录时间后才可参与模拟，同一代码同一信号日去重；已有待触发/持有/待核验记录时不叠加新单。只处理完整日线：有效日没有突破作废，开盘跌破止损或高于最高追价放弃，触发后模拟买价=max(开盘,触发)加滑点，仍须不超过追价上限。不能保证限价在实际盘口成交；日线缺乏成交顺序和深度，结果只能算粗略情景。

日内止损与目标都碰到时按止损先发生；同日买入也如此，即使真实低点可能在买入前。持有后跳空跌穿止损按更差的开盘价再扣滑点退出。估计滑点每边10基点；费用美股每边5基点、港股每边15基点，都是固定情景假设，不是券商实报价，未模拟最低佣金和税费取整。港股普通应税股票印花税买卖两边分别0.1%，实际还需核对交易所费用和券商收费。[香港税务局说明](https://www.ird.gov.hk/eng/faq/sdu.htm)

逐笔净收益=`卖价×(1−费用)/(买价×(1+费用))−1`，买卖价已含模拟滑点。目标是检验规则、持续收集前瞻样本，当前没有已验证的胜率或收益。没有组合资金、相关性、真实仓位、每手股数及财报日历，不能把逐笔收益均值当成账户回报或最大回撤。止损价也不是保证成交价。[FINRA订单类型说明](https://www.finra.org/investors/investing/investment-products/stocks/order-types)

下一阶段须在固定参数下积累前瞻样本，比较扣费收益、失败率与基准，再接入真实成本、事件日历、账户仓位约束。现有历史价格回放仍使用当前财报，不可冒充此策略的历史收益验证。本版未增加自动下单。
