# V6.11.0 排雷、私人账户测算与止损对照

本次实现全部四项工程功能，但尚未证明能提高收益。公开日线实验、私人账户条件性资金预留、实际券商订单是不同层次。本系统没有下单接口。

## 1. 大盘和财报

基准为恒指/标普500，要求最近50个完整交易日日线齐全，最新复权收盘严格高于MA50。低于或等于则BLOCK，缺数则UNKNOWN；都暂停新计划。候选及技术状态保留，旧持仓继续按原退出规则处理。这不是经过验证的熊牛划分。

Yahoo `get_calendar()` 的 Earnings Date 作为供应商预计日期；区间取最早日期。检查从观察时起到下一入场日开始最长10个交易日的窗口，预计日期在窗口内阻挡；若在窗口之后，表示供应商当前预计如此，不代表公告保证。没有未来日期、历史日期、无效日期、未来时间戳或证据超过4个自然日，均UNKNOWN。4日有效期用于周末跨越，财报改期风险仍存在。未提供其他新闻、增发、诉讼过滤。

只给实际技术计划和预备候选追加日历查询，现有待入场优先，最多40只、约180秒后停止启动新请求；预算外保持UNKNOWN，不伪装为通过。价格扫描最多18分钟，单个已启动请求可能继续等待。入场前重跑会重新核验未成交计划，失败撤销；没有运行就没有实时复核。

日线模拟成交再次检查保存在计划里的、入场前已观察到的排雷证据和基准日期，不使用今天的日历反推昨天可以成交。公开简报也检查财报证据过期；旧版没有排雷标记的计划不显示买价。

数据能力说明：[yfinance官方API](https://ranaroussi.github.io/yfinance/reference/api/yfinance.Ticker.html)。供应商预计日期不是发行人公告确认，没有SLA或日期完整性保证。

## 2. 私人账户条件性预留

用户暂不提供账户资料，默认ACCOUNT_REQUIRED，不输出股数。可先运行：

```powershell
python src/portfolio_risk.py --state state/mos_short_term.json
```

输出固定到被Git忽略的 `reports/private/position_sizing.json`，不会写公开状态、邮件或工作流产物，也不会在终端打印金额。未来把 `data/account_risk.example.json` 复制为被忽略的 `data/account_risk.private.json`，填写后：

```powershell
python src/portfolio_risk.py --state state/mos_short_term.json --account data/account_risk.private.json
```

必填：market(us/hk)、currency(USD/HKD)、带时区的asof、equity、peak_equity、cash、cash_basis、positions、pending_orders。账户快照最多24小时。cash口径明确为尚未扣下列挂单预留的现金余额，不能直接混用券商已经冻结挂单后的可用现金。positions/pending_orders每行包括 ticker、sector、shares、price、stop；price分别为持仓现价/挂单最高价格。空仓或无挂单明确填空列表。港股lot_sizes须逐代码给出整数每手股数，美股按整数股，不假设碎股。不能混合不同货币账户，峰值需在外部调整出入金影响。

初始限制：单笔预计止损风险不超过净值0.5%、单股票价值不超过10%、同一行业不超过25%、全部持仓与预留的预计止损风险不超过2%、最多五个代码。已有持仓和挂单先占用限额，再按相对强度、量比顺序逐笔预留；同一股票两策略只选一次，不能重复占用同一笔现金。数量向下取整到交易单位。风险估计使用最高追价、止损及原模拟费用/滑点，不是最坏可能损失。

净值较调整后的峰值回撤5%时，单笔新仓风险预算和单股上限均减半；回撤10%暂停新仓，不自动卖出现有持仓。现金、行业、总风险仍独立限制。数据无效、现金或持仓矛盾、止损已越过现价、行业或港股每手数缺失时暂停相应测算。不推断真实账户余额，不能保证回撤不超过20%。

此输出是按最高追价预留的研究预算。没有实时报价、盘口、已成交回报或可靠账户同步，不能直接提交到券商。

## 3. 价值标签

读取最新公开价值扫描，要求观察日期不超过8天且不在未来，排除估值下修/现有风险标记。以最新完整日线收盘替换旧报价并同比调整市值，再执行原严格入场与质量计算。只显示严格价值条件同时通过、质量/合理估值同时通过、未通过或证据待补，不以旧S/A评级加星，也不称为价值底。标签按收盘复核，不能当成追价上限处也满足价值门槛。

## 4. 固定止损和移动止损对照

新的guards-1计划同时开立两条独立实验记录：FIXED和BE_1R，后者ID增加be-1，基础价格计划不重复展示。实际初始R=模拟fill−初始stop，不是1ATR。至少完整持有一天（从持有第2个交易日开始）后，日内高点达到fill+R且当日未退出，才设置next_stop；下一交易日生效。买入当日高点可能发生在买入前，不能据此启动移动止损。

next_stop=fill×(1+买入费用率)/[(1−卖出费用率)×(1−卖出滑点)]，是估计成本下的参考线。原止损和目标优先判断；不能看到当天高点后用新止损回算当天低点。次日若跳空低于新止损，仍按更差开盘再扣滑点，可能亏损。[FINRA止损风险说明](https://www.finra.org/investors/insights/stop-orders-factors-consider-during-volatile-markets)

旧未发生的未排雷PENDING在计划入场前取消；已入场或其入场窗口已经开始的旧实验保留原口径，不用新证据改写历史。旧结果不并入新排雷对照。两策略×两退出版本分别计数和统计；另列完整配对比较，只有同一入场的两个退出版本都结束才计算收益差，未完成的一侧不参与。不是四份真实账户资金，也不以小样本均值宣称优势。
