## 利润口径

重新核对 [旺旺 2024/25 正式年报](https://www.hkexnews.hk/listedco/listconews/sehk/2025/0717/2025071700258_c.pdf) 印刷第 107 页（PDF 109 页）：

| 截止年度 | 归母净利润（人民币元） | 合并净利润（人民币元） |
|---|---:|---:|
| 2025-03-31 | 4,335,565,000 | 4,328,415,000 |
| 2024-03-31 | 3,990,474,000 | 3,983,179,000 |

两者都是报表披露数据。旧补录将合并利润放进未区分口径的 `net_income` 字段，本版改为 `net_income_attributable` 和 `net_income_consolidated`：前者映射普通股股东净利润，兼容供应商 `Net Income`；后者仅映射 `Net Income Including Noncontrolling Interests`，不会覆盖归母值。估值及十二个月校验优先读取 `Net Income Common Stockholders`，缺失时保持原 `Net Income` 回退。历史 `net_income` 输入保留兼容，新记录应使用明确口径，不允许同时提交 legacy 与 attributable。

这修复了已定位的映射问题，不保证供应商所有字段都与公告一致。资本开支、重述及其他利润差异仍会触发拒绝。拒绝记录新增 `conflicts`，保留字段、期间、供应商值、公告值；不放宽误差容忍，也不静默覆盖。SBC 仍未核实，保持缺失，不能由补录通过推导出可入场。

## SBC 分类

`sbc_coverage_status` 与 `sbc_missing_periods` 进入结果及诊断 CSV，报告按相同经营池汇总：

| 状态 | 含义 |
|---|---|
| NOT_FETCHED | 早期跳过或报价失败等导致尚未请求现金流表 |
| STATEMENT_UNAVAILABLE | 现金流表不可用 |
| LINE_MISSING | 表存在，但未返回 SBC 项目 |
| VALUES_MISSING | 有 SBC 项目，但检查范围内没有有效数字 |
| PARTIAL_HISTORY | 部分年份有值，部分缺失；保留缺失日期 |
| INSUFFICIENT_HISTORY | 检查范围都有值，但少于三年 |
| AVAILABLE | 最近最多五个非全空年度列中的 SBC 都有值 |

明确的零值保留，不将零判成缺失；供应商全空填充列不计入范围。该分类是证据诊断，不替代连续年份、有效 Owner FCF、SBC 历史覆盖及质量门槛。未返回 SBC 不代表公司实际没有股份支付。

## 时效调整

港股 GitHub workflow 计划在工作日香港时间 08:07 启动，为约 56 分钟冷启动全量扫描预留时间并避开整点。仍每天一次全量扫描，不增加重复邮件任务。`scan_started_at`、`scan_time`、`scan_duration_seconds` 分别记录程序扫描开始、完成及总耗时（含加载、取数和价格刷新），不等于整个 Actions job 耗时。

09:30 或之后生成的原定盘前报告，正文和邮件标题使用“延迟安全边际扫描（原定盘前）”；香港报告邮件日期按香港时区。手动报告不被误标成盘前延迟；美股流程不在本次时效变更范围内。该判断按时间阈值，不新增节假日、特殊开市或停市日历。

[GitHub 官方说明](https://docs.github.com/en/actions/how-tos/troubleshoot-workflows) 提醒定时事件可能延迟，整点是高负载时段。提前和错峰只能降低风险，不能保证准点投递；延迟报告仍保留供研究，标题不会继续伪装成正常盘前结果。
